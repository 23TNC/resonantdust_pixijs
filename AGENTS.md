# AGENTS.md

## Purpose
PixiJS v8 + TypeScript client for resonantdust. Connects to one or more SpacetimeDB modules under `../spacetime/server/modules/` (today: `shard` for game state, `chat` for chat) and renders the card / hex world.

## Important files
- `src/main.ts`: app bootstrap, fatal-error overlay, HMR teardown. Awaits `initDefinitions()` (boots the wasm content crate) before instantiating managers.
- `src/GameContext.ts`: service container passed to every scene. Single source of truth for cross-module wiring.
- `src/scenes/`, `src/server/`, `src/game/`, `src/ui/`, `src/assets/`: each has its own AGENTS.md with the module contract — read those before editing.
- `src/content/`: **submodule** (its own git repo, `resonantdust_content`). Contains the JSON catalogs AND the Rust crate that parses them. The wasm bundle lives at `src/content/pkg/resonantdust_content.{js,wasm,d.ts}` and is generated by `bin/content wasm`. Don't write through the submodule path without realizing you're editing a separate git repo. The repo-root `../../content/` is a symlink into this path so the SpacetimeDB compose mount and `bin/content` can address it from a stable location.
- `package.json`, `vite.config.ts`, `tsconfig.json`: build wiring.

## Conventions
- Each top-level dir under `src/` owns one responsibility and has an AGENTS.md with its contract — read those before editing.
- Validate at boundaries (data load, network, DOM); trust internal calls. Throw loudly on data inconsistency rather than degrading silently.
- Async lifecycle is the default — `onEnter`/`onExit`/`dispose()` are awaitable.
- Spacetime bindings are generated per-module: `../spacetime/server/generate-bindings.sh <module>` writes into `src/server/spacetime/bindings/<module>/`. Invoked automatically by `bin/st build`. Regenerate after any server schema change; never edit the generated files.
- Don't introduce module-level singletons. Hang shared services off `GameContext`.
- Logging: use `debug.log([...tags], ...)` from `src/debug/`, gated per-tag via `src/debug/index.ts`. Raw `console.log` is disallowed even for temp diagnostics.

## Pitfalls
- `src/content/` is a submodule; edits land in the content repo, not pixijs. Card-shape conventions live in [src/content/cards/AGENTS.md](src/content/cards/AGENTS.md).
- HMR safety depends on `SceneManager.dispose()` and `app.destroy()` running in `import.meta.hot.dispose`. Anything that registers global listeners (window resize, ticker callbacks, websocket) must be tearable down.
- This is the **third** rewrite. Goal: rewrite modules, not the repo. Maintain narrow contracts between modules so swapping one doesn't cascade.
